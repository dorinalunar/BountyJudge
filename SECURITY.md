# Security Policy
## Supported Versions
Currently, only the latest version of the `main` branch is supported with security updates.

| Version | Supported |
| :--- | :--- |
| Main | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability
Security is a top priority for BountyJudge. If you discover a security vulnerability within this project, please DO NOT post it publicly. 
Instead, please send a direct message or open a confidential security advisory on GitHub. 
We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress in resolving it. Do not submit a public pull request for security vulnerabilities.
