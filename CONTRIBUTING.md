# Contributing to BountyJudge

We love your input! We want to make contributing to BountyJudge as easy and transparent as possible.

## Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs or UI, update the documentation.
4. Ensure your code follows the standard style of this project.
5. Issue that pull request!

## Code of Conduct
By participating in this project, you are expected to uphold our Code of Conduct. Please be respectful to other contributors, provide constructive feedback, and foster an inclusive environment.

## Bug Reports
Use the GitHub Issues tab to report bugs. Please include:
- A quick summary of the bug.
- Steps to reproduce.
- What you expected would happen vs. what actually happened.
